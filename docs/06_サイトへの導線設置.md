# サイトへの導線設置（業者への依頼内容）

今回、外部制作業者に依頼するのは**リンクの追加だけ**です。フォーム本体は院内で作成・保守します。

---

## 1. 設置場所

### 必須：予約・お問い合わせページ（`/medical_checkup/reservation.php`）

現在このページは、電話とFAXの案内のみです。ここに**電話より上**の位置でWeb受付を案内します。

現在の構成：

```
# 予約・お問い合わせ
 ├ ページ内リンク（電話での予約・お問い合わせ／受診当日について）
 ├ ## 電話での予約・お問い合わせ
 │   TEL 095-813-5820（直通）/ FAX 095-813-5821
 │   ※電話受付時間：9：00～16：30（月～土）日・祝日・年末年始休み
 │   [お申込前にかならずお読みください]
 └ ## 受診当日について
```

変更後：

```
# 予約・お問い合わせ
 ├ ページ内リンク（インターネットでの予約依頼／電話での予約・お問い合わせ／受診当日について）
 ├ ## インターネットでの予約依頼  ← 新規
 │   [ボタン：健診・人間ドックの予約を依頼する]
 │   説明文（下記）
 ├ ## 電話での予約・お問い合わせ   ← 現状のまま
 └ ## 受診当日について             ← 現状のまま
```

電話より上に置く理由は明快です。**下に置くと電話をかける人が減らず、業務削減という目的を果たしません。**

### 推奨：健診トップページ（`/medical_checkup/`）

9枚のカードが並ぶ下に、既存の予約システムバナーがあります。その近くに同じ形式のボタンを1つ追加します。

---

## 2. 掲載する文言

### ボタン

```
健診・人間ドックの予約を依頼する
（24時間受付・折り返しお電話します）
```

### 説明文

```
インターネットから、24時間いつでも予約の依頼ができます。
ご希望の内容をお送りいただくと、健康管理センターの担当者から
折り返しお電話し、日程を確定します。

※このフォームの送信だけでは予約は確定しません。
※お急ぎの方、複数名でのお申し込み（事業所健診）は、
　お電話（095-813-5820）でご連絡ください。
```

**「予約する」ではなく「予約を依頼する」と書くこと。** 確定したと誤解されると、当日来院されて枠がない事態になります。

### 既存の予約システムバナーとの書き分け

同じページに入口が2つ並びます。申込者が迷わないよう、既存バナーの説明文も合わせて見直してください（文言は院内で確定させます）。

【ご確認いただきたいこと】

## 5. 公開前に確認すること

| # | 確認内容 |
|---|---|
| 1 | スマートフォンでボタンが押しやすい大きさか |
| 2 | 文字サイズ切り替え（小・中・大）でレイアウトが崩れないか |
| 3 | 別タブで開くか |
| 4 | 「予約を依頼する」という表現になっているか（「予約する」になっていないか） |
| 5 | 電話番号が正しいか（095-813-5820） |
| 6 | 既存の予約システムバナーと並んだときに、どちらを使うか判断できるか |

6は、受付担当ではなく**健診と無関係な職員に見てもらう**のが有効です。担当者は前提を知っているため迷いません。
