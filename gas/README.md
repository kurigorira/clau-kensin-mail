# gas/（未着手）

GAS Webアプリの実装場所。Claude Code で着手する。

## 想定ファイル構成

| ファイル | 役割 |
|---|---|
| `config.gs` | コース／オプション／受診区分／受付時間／宛先アドレスなど、変わる値を全部ここに集約 |
| `main.gs` | `doGet`（フォーム配信）／`doPost`（送信受付） |
| `form.gs` | 入力検証、受付番号の採番 |
| `sheet.gs` | 台帳への行追加、受付可能日の読み込み、重複チェック |
| `mail.gs` | 受付担当への通知、申込者への自動返信 |
| `notify.gs` | 受付可能日の枯渇・未更新を検知して通知（時間主導トリガー） |
| `index.html` | 画面（`mock/index.html` をそのまま移す） |

## 実装順序

1. スプレッドシート2シートを手で作る（台帳／受付可能日）
2. `config.gs` にコース定義を移す（`mock/index.html` から抜き出す）
3. `doGet` でモックをそのまま表示できるようにする
4. `doPost` → 検証 → 台帳へ1行追加
5. メール2通
6. 受付可能日をシートから読んでカレンダーに反映（モックの `AVAIL` を差し替え）
7. 枯渇・未更新の通知トリガー

## 注意

- 受付番号の採番は `LockService` で排他する。同時送信で重複すると台帳が壊れる
- 送信時に、選ばれた日付が**その時点でも受付可能か**をサーバ側で再確認する
- `doPost` は必ず try/catch。失敗時は完了画面を出さず、電話番号を大きく表示する
- 実在の受診者データをコードやテストに含めない
